## Projects

### [Ethere](https://github.com/MiraValeLab/Ethere-public)

一个面向长期使用的个人 AI 陪伴项目。

[查看产品演示 →](https://miravalelab.github.io/Ethere-public/)

它尝试回答三个问题：

- AI 如何更准确地理解用户当下的处境？
- 理解如何跨越不同会话持续存在？
- 关心如何转化为适度、可控的实际行动？

主要模块：

- **接触当下**：结合对话与当前线索理解正在发生的事
- **延续理解**：通过记忆与历史信息维持上下文
- **把关心落到行动**：协助管理任务、提醒与后续跟进
- **保持边界**：区分陪伴、建议和执行，保留用户的最终决定权
